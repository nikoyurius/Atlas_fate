# Fate Atlas

Доска: https://nikoyurius.github.io/Atlas_fate/

GitHub Pages публикует ветку gh-pages, папку / (root). index.html и 404.html содержат собранную доску; vendor — локальные библиотеки кубиков. Музыка воспроизводится напрямую с Internet Archive.

Комнаты и данные хранятся в существующем Sites API. При недоступности прямого API, включая проверенные российские сети, доска использует Render как запасной шлюз. Render нельзя останавливать, пока этот путь нужен игрокам. Права участников и ведущего проверяет API. Ключи и игровые данные в репозитории не хранятся.
